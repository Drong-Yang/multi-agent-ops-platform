# 电商运营 Agent 验收记录

日期 2026-11-21（北京时间）。测试使用本机融合工程、独立测试账号、虚构商品资料和真实火山云 RTC。语音输入由浏览器注入合成录音。下行语音以 WebRTC 音频包及音频能量的增长核对。

## 已通过

- **真实文字闭环**　PostgreSQL 和 Milvus 健康。SC-PB27 回答给出 568 克及资料来源，未知型号保留资料边界。咨询转任务后沿用知识快照，草稿通过事实检查，批准后产生对应版本的资产。新咨询选用已发布的 FAQ，撤回后排除。文本复验共 8 项通过。
- **工作台体验**　浏览器验证咨询转任务、任务回原轮次、批准后定位资产、FAQ 预填及引用回链。验证入口创建空会话，输入框预填问题。实测 390 像素视口下，资产页与咨询页没有横向溢出。
- **语音生产包**　修复前，浏览器因授权模块被输出为静态文件而无法进入通话。重新构建后，从工作台打开正式语音页可看到可用的通话入口。
- **接通、ASR 与 TTS**　合成语音被识别为「耳机拆封后能退吗」。真实回答解释查验拆包与超出必要查验的区别，保存了 5 条资料依据。首次通话中，下行音频包从 932 增至 1808，总音频能量从 0.618 增至 1.383。
- **挂断重连与两种打断**　首次挂断后重新拨通。助手正在播报时注入语音，原播报标为「已打断」，随后保存新问答且收到下行音频。另一通呼叫通过「点此打断」复核同一状态变化。最后挂断后活动 WebRTC 对端为 0，语音停止接口返回 HTTP 200。
- **语音进入内容流程**　用同账号在工作台打开已保存的语音咨询，从该轮创建内容任务，再通过任务定位回同一轮问答并展示其资料依据。
- **回归与构建**　发布版后端及原创作回归共 176 项，PostgreSQL 专项测试 24 项，前端与回调网关 Node 测试 32 项，通话状态 React 测试 7 项，Windows 启停脚本测试 7 项通过。两套前端生产构建及语音 TypeScript 类型检查通过。

## 单独记录的扩展场景

物理麦克风与扬声器兼容性、型号语音多轮追问、静音后再拨、订单类语音边界、长任务运行时同时通话，以及完整演示录屏未纳入这轮实测。产品型号和未知型号的文本边界已通过。

交付时保留本机工作台及其配套服务。测试通话已挂断。运行结束时按 [启停指南](MANUAL_ACCEPTANCE.md) 关闭服务和临时回调。
