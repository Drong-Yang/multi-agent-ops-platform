# 验收映射与交付边界

更新：2026-11-21。规格为本目录 PRD/技术与架构/Roadmap；以下区分已实现、自动化验证与用户待验收，不能用测试数量替代真实渠道验证。

- **AC-01 归属/语音映射：** `test_fusion_api.py`、`test_voice_gateway.py`、`test_repository.py` 覆盖账号隔离、专用语音授权、会话绑定、跨账号拒绝；真实 RTC 浏览器中的已保存语音会话和同账号任务回链已复核。
- **AC-02 同版知识：** `test_knowledge_facts.py`、`test_fusion_workflow.py` 覆盖快照身份、来源哈希、客服与写稿复用；`live-text-smoke.json` 保存真实文本证据。
- **AC-03 业务边界：** `test_legacy_rag.py`、`tests/legacy_customer`、API 测试及真实文本样本覆盖未知型号与未接入业务；真实语音已核对耳机售后政策回答。型号与订单类语音边界留待扩展场景复验。
- **AC-04 确认脱敏：** 知识/隐私与 API 测试覆盖手机号等脱敏、未确认拒绝；浏览器验证确认后转任务。
- **AC-05 来源关联：** API、Repo、融合图与浏览器报告覆盖 session→turn→insight→task→资产。
- **AC-06 恢复：** Repo/API/运行器测试使用独立 PostgreSQL 和检查点验证恢复、并发与异常队列；服务重启中不自动重放不确定付费任务。
- **AC-07 检查与门禁：** 事实/融合图/Repo 测试覆盖 SKU、数值、单位、政策条件、引用及审批哈希；检查为有限范围，不能承诺通用事实正确。
- **AC-08 批准与发布：** Repo/API/浏览器和真实文本链路覆盖正确版本批准、独立 FAQ 发布与实际选用。
- **AC-09 失效与撤回：** Repo/API 覆盖正文/知识换版排除，浏览器和真实文本验证撤回。
- **AC-10 幂等与故障：** Repo/API/运行器覆盖操作键、状态 CAS、恢复和外部调用不确定性；不承诺跨第三方完全一次执行。
- **AC-11 观察与版本：** 前端 API/state 测试、运行器/API 与浏览器覆盖 SSE、状态恢复、版本差异和事件隔离。
- **AC-12 语音：** `test_rtc_control.py`、`test_voice_gateway.py`、`test_voice_operations.py`、Node 网关和 React Jest 覆盖协议、鉴权、挂断异常、重连前采集、模式切换、清理及白名单；真实火山云 RTC 已覆盖合成语音上行、ASR、下行音频、语音插话、按钮打断和挂断重连。扩展场景见 `MANUAL_RESULTS.md`。
- **AC-13 分层评测：** 原客服四套测试的 28 项/110 条断言保留；147 题旧关键词评测为 136/147，历史失败不改写；原创作 13 项回归独立保留。Mock、真实文本和待测语音分别报告。
- **AC-14 隔离与复现：** 独立环境、数据库/集合/端口、来源哈希、许可和本机启动入口已交付；本轮不是清空机器后的全新安装验收。最终完整真实演示录屏待人工测试后补充。

## 实现取舍

- 采用模块化单体，保留 Vue 运营端与 React 语音端；没有为了统一框架重写 RTC SDK。
- 持久化使用 `fusion_records` JSON payload 加 kind/owner/CAS/source FK、操作幂等表和知识指针；并非规格每个逻辑实体独立建表。
- 复用原账号、创作节点、检查点、图像与 RAG/RTC 核心模块；增加 provider 注入和融合图，不替换稳定节点。
- 当前为单进程轻量运行器，不提供多 worker 高可用保证。
- 本机 UI/API 只在 loopback；临时公网只经过已鉴权回调网关。启动、关闭与云任务清理入口已具备，真实渠道结果见 `MANUAL_RESULTS.md`。

本轮为本机开发交付，文字闭环和核心真实语音链路已验收。完整演示录屏与扩展语音场景单独记录。
