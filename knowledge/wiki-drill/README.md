# 80 条 Wiki 闭环演练

本轮按 **20 个主题 × 4 个阶段**组织，题材来自模拟的文字客服、咨询案例、售后工单和复问。以项目电商演示快照的 104 个原始知识单元为基线，补写的是具体场景的核对步骤、适用范围和证据要求。

## Wiki 页面

- [商品规则](商品规则.md)收录 7 个主题，如双口供电、双屏兼容、换手机后的独立通话。
- [售后政策](售后政策.md)收录 7 个主题，如分包赠品、退货运费、混合支付和质检材料。
- [常见问题](常见问题.md)收录 6 个主题，如会议无声、无线充隔壳和外接存储识别。

## 演练记录

- [案例与复核](案例与复核.md)保留 80 条原话、摄入类型、基线路由、冲突处理、模拟复核和客服复测答复。
- [证据索引](证据索引.md)保留模拟材料全文和对应的原始语料单元 ID。
- [自检记录](自检记录.md)记录每批的有效版本、退出复用的旧版本、孤立主题、重复问法和待补证冲突。

## 重跑

从仓库根目录执行以下命令。脚本直接调用现有后端的咨询、线索确认、草稿、审核和发布处理函数。在临时 SQLite 库中执行，复核内容由本次会话编写。问答基线使用本地字面检索，测试进程禁止连接网络。输出包括上述 Wiki 页面和 `evals/runs/wiki-drill.json`，其中保留完整路由、出处及各审核资产版本。

```powershell
.\backend\.venv\Scripts\python.exe scripts\replay_wiki_drill.py
```

若本机虚拟环境导入 `_ssl` 或 `_ctypes` 时报 DLL 错误，可用同一项目工作区已安装的另一套 Python 3.13 和当前虚拟环境的依赖重跑。本轮在当前 Windows 工作区通过以下方式执行。

```powershell
$env:PYTHONPATH = (Resolve-Path 'backend/.venv/Lib/site-packages').Path
& '..\..\.runtime\python\cpython-3.13-windows-x86_64-none\python.exe' -X utf8 scripts\replay_wiki_drill.py
```

双向专题链接使用 Markdown 稳定主题 ID，可以在本目录点击查看。演练素材和模拟发布仅用于本地验收，真实工作台账户、数据库与向量索引均未写入。
